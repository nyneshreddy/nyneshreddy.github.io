## Raspberry Pi Web Server

This very website is being served from a Raspberry Pi running Nginx!

### Tech Stack
- **Raspberry Pi** - The server hardware
- **Nginx** - Web server serving static files
- **Next.js** - React framework with static export
- **Contentlayer** - Content management

### How It Works
The Next.js app is built locally and the static `out/` directory is deployed to the Pi's `/var/www/html/` directory.
